A fact goes in as PROVEN only when a machine proof checker accepts it. Everything else stays labeled MEASURED, CHECKED, REASONED or GUESS, so a reader, or an AI, never mistakes a guess for a fact.Formalized epistemology with machine verification. The PROVEN partition requires machine verification (Lean 4 kernel acceptance or exact arithmetic receipts); MEASURED, CHECKED, REASONED and GUESS demarcate non-proof epistemic bounds.
