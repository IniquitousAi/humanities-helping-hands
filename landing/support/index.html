Email us

Write to hello@humanitieshelpinghands.com. Ask us anything. Tell us if a label looks wrong. A real person reads it.

hello@humanitieshelpinghands.com, for questions, a label you think is wrong, a security report, or anything about the HHH connector.

hello@humanitieshelpinghands.com: questions, label disputes, security reports, and anything about the HHH connector (the MCP server at /mcp). One inbox, read by a person, no ticket system.

A label looks wrong

Send us the link to the fact. Say what looks wrong. If the check fails, we change the label and say why.

Send the fact's link and what you think is wrong. If a check fails, the label changes and the fact says why.

Send the fact's link and the claim you dispute. The fact's checker is re-run; if it fails, the label is lowered (for example from proven to a guess) and the fact carries the failing run as its reason.

A stamp you think is wrong

First check the stamp at Check a stamp. The stamp is math: if it says real, it's real. If you still think something is wrong, email hello@humanitieshelpinghands.com with the stamp, the thing it was stamped on, and what is wrong.

Check the stamp yourself at Check a stamp first: VALID or FAKE is math, not our opinion. If it reads VALID and you still have a serious problem, email hello@humanitieshelpinghands.com with all three: the stamp, the content it was stamped on, and what is wrong. A person reads it; there is no form and no automatic reply.

Run the stamp through /verify first (Ed25519 over the v2 message, plus the hash-chained log). If it reads VALID and you still dispute it, email hello@humanitieshelpinghands.com with the stamp JSON, the exact content (or its SHA-256), and the claim you dispute. There is no report endpoint: human reports never trigger a rollback; only a machine-detected hash drift or a failed signature does.

Report a security problem to the same address. The contact is also published at /.well-known/security.txt (RFC 9116). Please give us a chance to fix it before you disclose it.
